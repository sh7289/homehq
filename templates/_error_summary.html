{# Shared accessible error-summary pattern (Task 13). A form's route builds `errors` as a list of {"field_id": ..., "message": ...} dicts (one entry per validation failure) plus `errors_by_field` -- the same list keyed by field_id, for the inline per-field messages below. error_summary() renders a role="alert" landmark listing every failure, each one linking to the actual field via href="#field_id". base.html moves keyboard focus to it (tabindex="-1" makes that focusable) right after a failed submit, so a keyboard/screen-reader user lands on the summary immediately instead of hunting the page for what went wrong. `id` defaults to "error-summary" (every existing call site keeps working unchanged) but can be overridden so a page can render two independent instances at once -- e.g. add_errors and edit_error side by side -- if it ever needs to. Note base.html's focus-on-load script only targets the default "error-summary" id, so a second, differently-id'd instance won't auto-focus; that's fine for the common single-instance case this was built for. field_message()/field_attrs() render the matching inline message next to a given field, and the aria-invalid/aria-describedby attributes that tie the field to it -- call field_attrs() inside the input tag and field_message() just after it. Both take the same `errors_by_field` dict, not the `errors` list. This partial is deliberately generic (it only assumes {field_id, message} dicts) so any other form in the app can adopt it later without change. #} {% macro error_summary(errors, heading="Please fix the following before saving:", id="error-summary") %} {% if errors %}

{{ heading }}

    {% for err in errors %}
  • {{ err.message }}
    • {% endfor %}
{% endif %} {% endmacro %} {% macro field_message(errors_by_field, field_id) %} {% if errors_by_field.get(field_id) %}

{{ errors_by_field[field_id] }}

{% endif %} {% endmacro %} {% macro field_attrs(errors_by_field, field_id) -%} {%- if errors_by_field.get(field_id) -%} aria-invalid="true" aria-describedby="{{ field_id }}-error" {%- endif -%} {%- endmacro %}
